# Willow & Clay — E-Commerce Website

A responsive e-commerce website built as a full-stack learning project for Willow & Clay.

## 🚀 Features

- Product listing and product details
- Shopping cart functionality
- Increase and decrease product quantities
- Persistent cart using Local Storage
- Checkout page
- Dynamic product data
- Express.js backend
- Product API
- Responsive frontend

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Local Storage

## 📂 Project Overview

The project demonstrates how a frontend e-commerce interface can be connected with a simple backend API.

The application includes product browsing, product details, cart management, quantity updates, persistent cart data and a checkout workflow.

## 🧠 What I Learned

Through this project, I practiced:

- Building responsive web interfaces using HTML and CSS
- Developing interactive features with JavaScript
- Managing product and cart data
- Using Local Storage for persistent browser data
- Building a backend using Node.js and Express.js
- Creating and consuming a product API
- Organizing a web application into separate components
